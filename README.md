# 📐 RawCert - Premium Certificate Scene Generator

> Turn raw PDFs and landscape certificates into gorgeous, scroll-stopping social media showcases. Built with a bold, high-contrast Neo-Brutalist design system.

---

## ✨ Why RawCert?

Sharing accomplishments on **LinkedIn**, **Twitter/X**, or **Instagram** is essential for professional branding. However, raw landscape images or PDF links often get auto-cropped, shrunk, or ignored by fast-scrolling users. 

**RawCert** wraps your credentials inside a high-fidelity macOS window mockup placed on cinematic gradient backdrops, instantly elevating the visual impact and engagement of your posts.

| standard sharing | with RawCert 🚀 |
| :--- | :--- |
| ❌ Plain landscape certificate gets cropped. |  Beautiful, centered macOS mockup framing. |
| ❌ Low visual hierarchy in busy feeds. |  Stunning radial & linear gradient backgrounds. |
| ❌ PDF links require clicks to view. |  High-res PNG ready to read immediately. |
| ❌ Fixed default aspect ratios. |  Preset grids optimized for every platform feed. |

---

## 🎨 Design Philosophy: Neo-Brutalist Styling

RawCert is crafted using a **Neo-Brutalist design language**. This aesthetic was intentionally selected because:
* **High Contrast**: Keeps the editor interface extremely readable and punchy.
* **Sharp Edges**: The solid borders and sharp drop shadows make elements pop off the screen.
* **Bold Presence**: Stands out from the sea of soft, white, rounded minimalist SaaS templates.

> [!NOTE]  
> The heavy borders, custom drop-shadow inputs, and rich retro/cyber palettes are designed to look state-of-the-art and feel premium to work with.

---

## ⚡ Core Features

- **Drag-and-Drop Uploader**: Supports both high-resolution images and multi-page PDF rendering (utilizing PDF.js).
- **Interactive Layout Controls**: Sliders to adjust shadow intensity, border thickness, corner roundness, and border tint.
- **Backdrop Wallpaper Engine**: Choose from curated preset gradients or set custom hex colors.
- **Optimized Aspect Ratios**:
  - `16:9` – Best for standard LinkedIn & Twitter desktop feeds.
  - `1:1` – Best for Instagram grids & square posts.
  - `4:3` – Perfect classic tablet presentation.
  - `Original` – Fits the exact proportions of your uploaded file.
- **One-Click PNG Export**: Uses `html2canvas` at $2\times$ scale for crystal-clear, print-ready output.

## 🛠️ How to Use

RawCert is a static, self-contained single-page application. There are no external servers or complex installations required.

### Quick Start
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/rawcert.git
   ```
2. Double-click [index.html](file:///d:/Deep/index.html) to open it in your browser.
3. Drag your certificate file into the active uploader zone, customize the backdrop, and click **Download Scene**.
